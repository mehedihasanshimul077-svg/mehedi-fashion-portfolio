# Md. Mehedi Hasan — Fashion Portfolio

A free, static portfolio website built from the supplied fashion portfolio and CV.

## Files
- `index.html` — complete website
- `assets/` — optimized portfolio images
- `MD-Mehedi-Hasan-CV.pdf` — supplied CV

## Publish for free
### GitHub Pages
1. Create a free GitHub account.
2. Create a new public repository.
3. Upload everything inside this folder.
4. In the repository, open Settings → Pages.
5. Choose “Deploy from a branch”, select `main` and `/root`, then Save.
6. GitHub will give you a public website address.

You can later connect a custom domain if you buy one. No paid hosting is required.
